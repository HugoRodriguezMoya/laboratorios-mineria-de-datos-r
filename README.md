# Laboratorios de Minería de Datos en R

Laboratorios de la asignatura de **Minería de Datos** (Grado en Business Analytics, UNIE), realizados **en equipo**.

| Notebook | Contenido |
|---|---|
| `lab_2_2_preprocesamiento_de_datos.ipynb` | Etapas de preprocesamiento: limpieza, tratamiento de nulos y atípicos, transformación de variables |
| `lab_2_3_contrastes_de_hipotesis.ipynb` | Principales contrastes de hipótesis sobre muestras |
| `lab_3_1_regresion_lineal_simple.ipynb` | Regresión lineal simple sobre el dataset `airquality` |
| `lab_3_2_regresion_lineal_multiple.ipynb` | Regresión lineal múltiple sobre el dataset `Boston` (precio de la vivienda) |
| `lab_3_3_regresion_no_lineal.ipynb` | Modelos de regresión no lineal |
| `lab_4_1_clasificacion_supervisada.ipynb` | Introducción a los modelos de clasificación supervisada |
| `lab_4_2_entrenamiento_y_evaluacion_clasificadores.ipynb` | Entrenamiento, validación y métricas de modelos de clasificación |

## Tecnologías
R

## Cómo ejecutarlo
Jupyter con kernel de R (IRkernel) o Google Colab con R. Los resultados ya aparecen guardados en cada notebook.
